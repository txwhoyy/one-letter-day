One letter for a whole day: **G — grinding**. This entry writes exactly one character, the letter G, standing for a day spent grinding through work all night — head down, hours blurring, still going. It deliberately skips the bounty description's own example letters (A, F, Z) for a sharper, deadpan-funny pick: a specific picture of a day, not a vague mood, and one that lands at once because it is true.

## Run it

```sh
node main.ts
```
